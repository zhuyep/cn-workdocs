# Security policy / 安全策略

## Reporting / 报告方式

Please use GitHub private vulnerability reporting for security issues. Do not open a public issue containing confidential documents, personal data, credentials, or an exploitable vulnerability.

安全问题请使用 GitHub 私密漏洞报告。请勿在公开 Issue 中提交机密材料、个人信息、凭据或可被利用的漏洞细节。

## Data boundary / 数据边界

The skill itself is plain text and sends no data anywhere. The agent or tools used with it may access files, browsers, models, or external services. Review those products' permissions and data-handling policies before using confidential material.

Skill 本身是纯文本，不会主动发送数据。但实际使用的智能体和工具可能访问文件、浏览器、模型或外部服务；处理机密材料前，请核查相应产品的权限与数据政策。
